# Wix Headless + Astro

An experiment in using **Wix as a headless CMS** — custom frontend, Wix backend.

## Why headless Wix?

I don't love Wix as a platform for building websites. The editor-first workflow just isn't how I like to ship frontend work.

But the client already runs their site on Wix — analytics, forms, SEO, contacts, the whole setup. Ripping that out and starting over wasn't the right call. So I went headless: keep Wix as the CMS and business backend, own the frontend myself.

Turns out that's a pretty fun way to work with a platform you'd normally avoid.

## Stack

- **Astro** + React islands for the UI
- **Wix Headless** for CMS, forms, and hosting
- Custom design system on top

## What this project explores

- Using Wix as a headless CMS instead of a page builder
- Letting the client keep existing Wix tooling (analytics, forms, SEO, etc.)
- Shipping a fully custom frontend without abandoning their current ecosystem
