# Goal

Replace the visually heavy social-icon treatment with a compact, polished brand-color presentation in both the sticky header utility bar and footer, then release the validated Wix-managed Astro site to production.

# Plan

1. Refine the reusable branded social-link style by removing white circular surfaces, borders, shadows, and vertical motion while retaining recognizable Instagram, Facebook, and YouTube colors.
2. Apply the same branded variant to the footer, preserving accessible link names, keyboard focus, reduced-motion compatibility, secure external-link behavior, and analytics metadata.
3. Validate formatting, TypeScript, and the Wix production build; create a Wix preview only if needed to inspect deployment output.
4. Release the final frontend once with the Wix managed-site release command, verify the published site output, and report both the live site and dashboard links.

Scope and assumptions: this iteration changes only the existing social-link presentation and footer usage. It does not alter social URLs, backend content, installed Wix apps, or booking behavior. The user explicitly authorized the production release.
