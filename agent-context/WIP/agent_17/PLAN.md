# Goal

Make homepage sections visually distinct after relaxing scroll snapping, without increasing whitespace or changing the content layout.

# Plan

- Preserve all current section padding, content, and responsive layout.
- Strengthen the contrast between the existing paper and surface section tones.
- Add a restrained inset accent at ordinary homepage section boundaries while leaving the existing ridgeline as the prominent decorative transition.
- Scope the new treatment to the homepage so inner pages retain their current presentation.
- Build the Astro/Wix project, release the changed frontend once, and verify the published homepage uses the updated styles.
