# Goal

Make the Featured services section visually balanced by preventing a single fourth service card from wrapping onto its own desktop row, while preserving useful access to all services.

# Plan

1. Locate the Featured services component, its service data source, and responsive layout styles.
2. Choose the smallest content/layout adjustment that fits the existing site structure and keeps mobile behavior usable.
3. Implement the change without altering unrelated pages or user work.
4. Run the relevant build, tests, and targeted source checks; record the actual result and any remaining manual checks.

Scope is limited to the Featured services presentation and directly related service navigation. The current assumption is that all four services should remain discoverable unless an existing dedicated Services page makes a curated three-card homepage treatment clearly preferable.
